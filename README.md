# HR Analytics | SQL & Tableau

## 📊 Project Overview

This project analyzes a large HR dataset containing approximately **2,000,000 employee records** to explore workforce composition, employee performance, compensation, and employee attrition.

The project was built as an end-to-end data analytics workflow, beginning with data profiling and quality assessment in **Microsoft SQL Server**, followed by data cleansing and validation, and finally visualization and business analysis using **Tableau**.

The primary objective is to transform a large and imperfect HR dataset into reliable information that can help answer practical workforce and HR-related business questions.

---

## 🎯 Business Objective

Organizations need to understand their workforce in order to make informed decisions about employee retention, workforce planning, compensation, and performance management.

This project focuses on answering questions such as:

- Which departments have the highest employee attrition?
- How is the workforce distributed across departments and job levels?
- How does employee performance vary between departments?
- How does salary vary across departments, job levels, and employee experience?
- How is the workforce distributed across different work modes?
- Are there employee groups or departments that may require further HR investigation?
